# Unique Dummy IDs

## This plugin requires [Harmony](https://github.com/pardeike/Harmony/releases/)
Download the Harmony-Fat.zip and extract `0Harmony.dll` in the `net48` folder to your plugins folder.

## This plugin adds unique IDs for Dummies in SCP: Secret Laboratory.
Dummy UserIDs use their connectionIDs for their UserIDs and end with `@Dummy`</br>
Example: `65535@Dummy`

### The main point of this plugin is to allow people to debug plugins or issues with their servers with anything that relates to a UserID. Dummies only use the same `DUMMY_ID` which makes it hard to debug issues with UserIDs alone or breaks things further.
### (These are still Dummies and will have their tag and everything, only the UserID of the Dummy is changed)
